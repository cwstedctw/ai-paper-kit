# 練習資料，不是原始資料

> 這個資料夾現在放的 `study_data.csv` 是依論文表格**重建的練習資料**，每個人的分數都是假的，不能拿來下研究結論、不能投稿。CSV 單獨傳出去時看不出這一點，傳給別人要一起附上這份說明。換成自己的研究資料後，把這個標題和這段刪掉。

## source/data：研究資料

這裡放原始資料。AI 只讀、不改；清理和轉換一律寫在 `source/scripts/analyze.py` 裡。

## 現在裡面是什麼（範例）

範例用的是一篇已發表的居服員失智照護訓練研究（2021 年，*BMC Geriatrics*，開放取用、CC BY 4.0；完整書目是 `source/refs/refs.bib` 裡的 Su2021）：https://doi.org/10.1186/s12877-021-02075-3

| 檔案 | 是什麼 |
|---|---|
| `study_data.csv` | **重建的練習資料，不是原始資料。** 140 人（兩組各 70），由 `tools/make_practice_data.py` 依論文表 1、表 2 的人數、平均、標準差反推。平均、標準差、t 檢定、效果量對得上論文；每個人的分數是假的，不能拿來下研究結論 |
| `published_values.csv` | 從論文表 1、表 2、表 4 抄下來的數字，分析程式拿它跟重算的結果對照 |

`study_data.csv` 每人一列：

| 欄位 | 意思 |
|---|---|
| `id` | 代號（I001…介入組、C001…對照組），不是真人 |
| `group` | `intervention`＝介入組（行動學習＋輔導支持）；`control`＝對照組（8 小時課堂講授） |
| `age`、`sex`、`marital`、`education`、`job` | 年齡、性別、婚姻、教育程度、全職或兼職 |
| `years_worked` | 當居服員的年資（年，小數一位） |
| `training` | 前一年在職訓練時數，分組：`none`（沒有）、`<10 h`、`10-20 h`、`>20 h` |
| `dementia_training` | 失智症相關訓練時數，分組：`none`（沒有）、`<2 h`、`3-6 h`、`7-12 h`、`>12 h` |
| `dkas_t0`、`dkas_t1`、`dkas_t2` | 失智症知識 DKAS（0–50）：前測、第 12 週、第 24 週 |
| `adq_t0`… | 失智症態度 ADQ（19–95），三個時間點 |
| `scids_t0`… | 失智照護能力感 SCIDS（17–68），三個時間點 |

級距後面加「 h」（小時），是為了不讓 Excel 把 `3-6`、`7-12`、`10-20` 自動顯示成日期（例如「3月6日」）。用 Excel 打開只看就好，關掉時按「不要儲存」。

`published_values.csv` 每一列是論文上的一個數字：`table`（T1、T2、T4＝論文的表 1、2、4）、`variable`、`level`、`group`、`stat`（mean、sd、n、p、d…）、`value`。

## 換成自己的資料：四個條件都符合才可以放

**Private 不等於可以放受試者資料。**

1. **去識別化**：不放姓名、學號、病歷號、聯絡方式；拼起來認得出人的資訊（住哪裡、職業、家庭成員、日期、少見的病史）也要處理掉。
2. **IRB 允許**：核准的計畫書、同意書範圍，允許用**每一家**會碰到這份資料的 AI 工具（接力模式會同時送給 OpenAI 和 Anthropic）；而且這些 AI 帳號都關掉了「用我的資料改進模型」，或用的是學校、企業方案。
3. **允許存放在 GitHub**：資料管理計畫和學校規範，允許把資料放在 GitHub 這種境外雲端；推上去之後，GitHub 的自動編譯也會在它的雲端機器上讀這份資料。
4. **這個資料夾在 GitHub 上是 Private**。

有一條不確定，就先不要放，去問 IRB。**核准文件沒有寫到生成式 AI 或境外雲端的，不要自己推定可以，先問 IRB 或學校的資料管理窗口。** 符合的話：照上面的格式寫一份欄位說明，請 AI 改 `source/scripts/analyze.py` 上面 `DATA` 那一行和讀的欄位，再跑一次 build。

**檔案格式**：用 Excel 另存新檔，存檔類型選「CSV UTF-8（逗號分隔）」。繁體中文版 Excel 預設的 CSV 不是 UTF-8，程式會讀不進來。

**第 1、2 條符合，但不能放境外雲端（第 3 條不符合）**：可以只在自己電腦上跑。在 `.gitignore` 加一行 `source/data/你的資料檔名.csv`，資料就不會推上 GitHub；GitHub 雲端編譯會因為沒有資料而失敗，到儲存庫的 Settings → Actions 把它停用。

**開新論文時資料不會被複製**：`tools/new_paper.py` 把舊論文收進 `examples/` 時，只帶這份 README，資料檔留在 `source/data/`；`.gitignore` 也擋了 `examples/` 裡的資料檔。不要自己把資料複製到別的資料夾。

**用原始研究資料時**：資料能放在哪裡、能交給哪個 AI、能不能上雲端，照上面四個條件確認；確認之前，不要放進 AI 的工作資料夾，也不推上 GitHub。要做需要個人層次資料的分析（例如 GEE），設定要跟原本用的統計軟體逐項對齊，結果才比得起來。
